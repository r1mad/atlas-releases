# Atlas releases

Download **Atlas.dmg** from the [latest release](../../releases/latest). Works on Apple Silicon and Intel Macs.

1. Open the DMG and drag **Atlas** into **Applications**.
2. First launch (unsigned build): right-click Atlas → **Open** → **Open**.
   If still blocked: `xattr -dr com.apple.quarantine /Applications/Atlas.app`
3. Allow **Accessibility** (System Settings → Privacy & Security → Accessibility → Atlas on).
4. Most features start off. In Atlas Settings turn on Command Bar (⌥Space), Window shortcuts (⌃⌥A/S/D = left/middle/right third) and Dynamic Island sections.

From v0.2.0 Atlas checks this page for updates and offers a one-click update.
